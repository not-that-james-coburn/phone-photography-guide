# Phone Photography — You Can Take Better Photos

A self-contained, static 20-page HTML picture book for beginner mobile photographers.

## Included
- `index.html` — 20-page book
- `styles.css` — responsive portrait layout and CSS illustrations
- `script.js` — progress bar and contents drawer

## Hosting
Upload the files to Netlify, GitHub Pages, Cloudflare Pages, or another static host.

## Images
This first build uses dependency-free CSS illustrations as visual placeholders. The panels are intentionally designed so they can later be replaced by real example photographs without changing the overall layout.
