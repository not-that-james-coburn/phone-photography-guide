# Phone Photography — You Can Take Better Photos

Updated 20-page responsive static HTML picture book.

## What's new
- Real example photographs replace the CSS-only placeholders on the teaching pages.
- Photos are annotated with simple grids, labels, crops, and before/after treatments.
- The existing portrait/mobile-first layout is preserved.
- `IMAGE-CREDITS.md` documents the selected Unsplash photographs and their source pages.
- Images are referenced from Unsplash's image CDN, so the project remains lightweight.

## Hosting
Upload the files to Netlify, GitHub Pages, Cloudflare Pages, or another static host.

## Important
The current images are remotely loaded from Unsplash. For a fully self-contained/offline package, download the credited images into an `images/` folder and change the `<img src>` values accordingly.
